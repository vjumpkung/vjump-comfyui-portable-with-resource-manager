## Command notation

On Windows, production node commands resolve to absolute paths:

- **Git** = `<root>\tools\git\cmd\git.exe`, with common arguments `-c core.longpaths=true -c advice.detachedHead=false -c core.symlinks=false -c submodule.recurse=false -c protocol.allow=never -c protocol.https.allow=always -c credential.helper= -c core.fsmonitor=false -c core.hooksPath=<app hooks path>`, then optional `-C <repo>`, then `-c status.relativePaths=true -c core.quotePath=true` and the subcommand. Git also gets a temporary `GIT_CONFIG_GLOBAL` and `GIT_CONFIG_NOSYSTEM=1`. Production disables local Git remotes; `protocol.file.allow=always` is test-only. The builder is [`git.rs:193`](D:/vjump/vjump-comfyui-portable-with-resource-manager/crates/infrastructure/src/custom_nodes/git.rs:193); Windows Git resolution is [`tools.rs:208`](D:/vjump/vjump-comfyui-portable-with-resource-manager/crates/infrastructure/src/environment/tools.rs:208).
- **UV** = `<root>\tools\uv\uv.exe --no-config ...`, from [`packages.rs:40`](D:/vjump/vjump-comfyui-portable-with-resource-manager/crates/infrastructure/src/environment/packages.rs:40).
- Each Git command with `-C <repo>` has **two app-spawned Git processes in order**: first the local-config check `config --local --no-includes --null --list`, then the requested subcommand. The check and primary command are separate calls in [`git.rs:290`](D:/vjump/vjump-comfyui-portable-with-resource-manager/crates/infrastructure/src/custom_nodes/git.rs:290).
- Git’s `CommandSpec.cwd` is unset: `-C` makes Git operate from the node directory, while the OS process inherits the app’s cwd. Git clone has no `-C`. UV and Python set `CommandSpec.cwd` where noted. The runner launches `Command::new(&spec.program)` and applies `current_dir` only when one was supplied: [`process.rs:465`](D:/vjump/vjump-comfyui-portable-with-resource-manager/crates/infrastructure/src/shared/process.rs:465).

## 5. Bare-name executables

For production custom-node flows, the app’s direct `CommandSpec` programs are not bare names: Git resolves to the managed Git path, UV to `<root>\tools\uv\uv.exe`, and Python to `<env>\Scripts\python.exe`. Python path construction is [`layout.rs:106`](D:/vjump/vjump-comfyui-portable-with-resource-manager/crates/infrastructure/src/environment/layout.rs:106). Production composition uses `GitNodes::new()` ([`stack.rs:132`](D:/vjump/vjump-comfyui-portable-with-resource-manager/crates/infrastructure/src/custom_nodes/stack.rs:132)).

Tests do use bare-name lookups such as `Command::new("git")`; those are test helpers, not the production custom-node spawn path. Whether UV or Git launches additional **transitive** processes internally is not established by these app command builders.

## 6. Guarded requirements and refusal rules

The guarded root `requirements.txt` is read through the node guard, replaced in UV arguments with `-r -`, and supplied through stdin. `with_guarded` sets cwd to the guarded node directory and retains the guard ([`packages.rs:67`](D:/vjump/vjump-comfyui-portable-with-resource-manager/crates/infrastructure/src/environment/packages.rs:67), [`packages.rs:88`](D:/vjump/vjump-comfyui-portable-with-resource-manager/crates/infrastructure/src/environment/packages.rs:88)). Nested includes and local paths therefore keep their relative-to-node behavior.

Current preflight behavior in [`packages.rs:98`](D:/vjump/vjump-comfyui-portable-with-resource-manager/crates/infrastructure/src/environment/packages.rs:98) through [`packages.rs:299`](D:/vjump/vjump-comfyui-portable-with-resource-manager/crates/infrastructure/src/environment/packages.rs:299):

- Nested relative `-r` and `-c` includes are supported when they resolve to bounded regular files; recursion is bounded and duplicate files are deduplicated.
- Existing relative local wheel paths such as `./localpkg-...whl` are supported. The fixture also covers a local wheel in a constraint, `cons_pkg @ ./cons_pkg-...whl`.
- A local source directory such as `./pkg` or `../source` is refused.
- `file:` URLs and unsupported URL/path forms are refused by preflight.
- Editable forms (`-e`, `--editable`) and unknown options are refused.
- Refusal is `ProvisionError::Failed("Requirements need external inspection before previewing; editable and source-directory requirements are not permitted.")` ([`packages.rs:98`](D:/vjump/vjump-comfyui-portable-with-resource-manager/crates/infrastructure/src/environment/packages.rs:98)). `preview_install` calls preflight before spawning UV ([`packages.rs:412`](D:/vjump/vjump-comfyui-portable-with-resource-manager/crates/infrastructure/src/environment/packages.rs:412)).

The compatibility fixture is now at [`tests.rs:5614`](D:/vjump/vjump-comfyui-portable-with-resource-manager/crates/infrastructure/src/custom_nodes/tests.rs:5614). It includes nested `-r`/`-c`, `./wheel.whl`, and `name @ ./wheel.whl`; it asserts stdin uses `-r -`, cwd is the guarded node directory, and UV resolves all three wheel paths under that directory ([`tests.rs:5642`](D:/vjump/vjump-comfyui-portable-with-resource-manager/crates/infrastructure/src/custom_nodes/tests.rs:5642), [`tests.rs:5681`](D:/vjump/vjump-comfyui-portable-with-resource-manager/crates/infrastructure/src/custom_nodes/tests.rs:5681), [`tests.rs:5690`](D:/vjump/vjump-comfyui-portable-with-resource-manager/crates/infrastructure/src/custom_nodes/tests.rs:5690)). ## 8. DLL-search test

`windows_children_exclude_cwd_from_default_dll_search` creates a temporary cwd containing a uniquely named invalid DLL, then starts the helper test process with that cwd ([`process/tests.rs:674`](D:/vjump/vjump-comfyui-portable-with-resource-manager/crates/infrastructure/src/shared/process/tests.rs:674), [`process/tests.rs:679`](D:/vjump/vjump-comfyui-portable-with-resource-manager/crates/infrastructure/src/shared/process/tests.rs:679)). Inside the helper, the first `LoadLibraryW` accepts either error 193 (the cwd DLL was selected but is invalid) or 126 (not found). The helper then explicitly calls `initialize_tool_policy()`, retries, and requires error 126 ([`process/tests.rs:707`](D:/vjump/vjump-comfyui-portable-with-resource-manager/crates/infrastructure/src/shared/process/tests.rs:707), [`process/tests.rs:716`](D:/vjump/vjump-comfyui-portable-with-resource-manager/crates/infrastructure/src/shared/process/tests.rs:716)).

So this fixture demonstrates that calling the policy initializer **inside the helper process** excludes cwd from that process’s DLL search. It does not assert that an app-spawned UV/Git/Python child starts with the policy already applied. The runner calls `SetDllDirectoryW("")` before spawning, but the repository residual records that this setting is not inherited by children ([`windows.rs:27`](D:/vjump/vjump-comfyui-portable-with-resource-manager/crates/infrastructure/src/shared/process/windows.rs:27), [`windows.rs:165`](D:/vjump/vjump-comfyui-portable-with-resource-manager/crates/infrastructure/src/shared/process/windows.rs:165), [residual row 6](D:/vjump/vjump-comfyui-portable-with-resource-manager/docs/handoff/evidence/s3-residuals.md:12)).
