## Approved plan
1. Port: new trait `ExtraModelPathsWriter { async fn generate(&self, root: &Path, base: &Path) -> Result<(), RuntimeError>; async fn remove(&self, root: &Path) -> Result<(), RuntimeError>; }` in `crates/application/src/comfy_runtime/ports.rs` (separate from `ExtraModelPaths`, so read-only consumers and fakes stay untouched). `YamlExtraModelPaths` implements both.
2. Use case `ManageExtraModelPaths::new(EnvironmentDeps-or-the-existing-root-provider, Arc<dyn ExtraModelPathsWriter>)` with `generate(base)` and `remove()`; the root comes from the current root provider (`root.current()` as other use cases do). Wire the writer into the desktop runtime adapters and the use case into the comfy services. New error `RuntimeError::ExtraPathsRejected(String)` → IPC code `extra_model_paths_invalid` (message passed through; it never contains secrets) with an error-mapping test.
3. Commands `comfy_generate_extra_model_paths { basePath: string }` and `comfy_remove_extra_model_paths` (manager window only; ACL + permissions + bindings + acl.rs cases). After a successful write, trigger the existing library rescan (`services.library.rescan` or equivalent); rescan errors are logged only.
4. File semantics (infrastructure `extra_paths.rs`, writer side):
   - App section key `vjumpkung_desktop`. File's first line: `# Managed by vjumpkung ComfyUI desktop. Other sections are kept; the vjumpkung_desktop section is rewritten by the app.`
   - Section: `base_path` = the user's absolute path (trailing separators removed, never a `\\?\` form), `is_default: false`, then keys sorted and de-duplicated case-insensitively = the REQUIREMENTS §4.6 primary names (`checkpoints, diffusion_models, text_encoders, vae, loras, controlnet, clip_vision, embeddings, upscale_models, latent_upscale_models, style_models, hypernetworks, photomaker, gligen, audio_encoders, model_patches, vae_approx, diffusers`) plus `configs`, plus every existing subfolder of the install's `ComfyUI/models` that is a valid `SafeFileName`, does not start with `.`, and is not `clip` or `unet`. Each value `<name>/`; `text_encoders` gets a second line `clip/` only if `<base>/clip` is a directory, `diffusion_models` gets `unet/` the same way (multi-line value joined with `\n`).
   - Create missing primary folders under the base (`create_dir_all` for the base itself, `create_dir` per category); if a FILE with a category's name exists → refuse; existing folders (and links) are left as they are.
   - Emit with `serde_yaml_ng` (correct quoting for spaces/Thai); write with `crate::shared::fs::atomic_write`.
5. Existing file: refuse with "extra_model_paths.yaml could not be updated safely: {reason}. Edit or move it, then retry." when it is a link/reparse point, > 1 MiB, not UTF-8, malformed YAML, the top level is not a mapping (null/empty counts as empty mapping), or any section contains a `<<` merge key. Otherwise keep the other sections as data (comments are lost). If the file exists and its first line is not the app header, first copy it to `<root>/data/backups/extra_model_paths-<YYYYMMDDTHHMMSSZ>.yaml` (create `data/backups`; never write a backup next to the original — ComfyUI's `.gitignore` covers only `extra_model_paths.yaml`, a sibling would dirty the checkout and block app updates). `remove()` deletes only the app section and deletes the file when no section remains; it never deletes folders; a missing file/section is a no-op success.
6. Choose the real folder."; `<root>/ComfyUI` missing → "ComfyUI is not installed yet."
